Tool guide

  1. Add your maps. Browse for .ymap or CodeWalker XML files, or choose a folder to include its subfolders.
  2. Scan for conflicts. Check which maps share placements, then continue to field review.
  3. Choose values. Use the source selector on each changed field to choose which value to apply.
  4. Export your maps. Download the YMAP ZIP to get every binary map. Folder imports keep their original folder paths. Matching paths go into separate source folders. Choose Export XML for individual CodeWalker files.

Each source map exports separately. If the maps stream together, review overlapping placements in CodeWalker before deploying them.
